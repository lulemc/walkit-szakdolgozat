# walkit-szakdolgozat
Városi sétatervező alkalmazás React Native környezetben 

# Frontend
Indítás: 

    npm i
    npm start

A mobilon való teszteléshez előzetesen telepíteni kell az [Expo Go](https://expo.dev/go) alkalmazást.
# Backend

Indítás: 

    npm i
    npm run dev

Az alkalmazás a `localhost:4000`-en fog futni
